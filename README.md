## 📝 프로젝트 소개

이 프로젝트는 **[Now in Android](https://github.com/android/nowinandroid)** 프로젝트를 분석하여:
- 주요 구조와 동작 원리를 이해하고,
- 샘플 구현과 관련 기술들을 학습 및 문서화하는 것을 목표로 합니다.

**작성된 문서는 다음을 포함합니다:**
- 프로젝트 구조 분석
- 기술 스택 학습 (Hilt, Coroutine, Navigation 등)
- 샘플 구현 코드 및 관련 자료
