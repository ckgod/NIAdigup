---
title: 6.1 코루틴(Coroutines)
---

코루틴(Coroutines)은 비동기 프로그래밍을 간소화하기 위해 고안된 **경량 스레드** 개념입니다.
Kotlin에서 공식적으로 지원하고 있으며, 안드로이드 개발에서 특히 네트워크 통신, 데이터베이스 I/O 또는 긴 처리가 필요한 작업을 간단하고 효율적으로 구성하기 위해 널리 사용됩니다.
[**동시성(Concurrency)** 과 **비동기(Asynchronous)**](6-1-1-동시성과-비동기.md) 흐름을 직관적으로 표현하고 관리할 수 있게 도와줍니다.



## 1. 코루틴의 등장 배경

### 1.1 콜백(Callback) 방식의 한계

네트워크 통신이나 파일 I/O와 같은 시간이 오래 걸리는 작업을 단순히 콜백으로 처리하면, 코드가 분산되고 중첩 구조(콜백 지옥, *Callback Hell*)로 인해 복잡성이 커집니다.

```kotlin
// 예시: 콜백 지옥이 발생하는 예시
fetchDataFromNetwork { data ->
    saveDataToDatabase(data) { result ->
        showResult(result) { 
            // ...
        }
    }
}
```

### 1.2 스레드(Thread) 직접 제어의 부담

안드로이드에서 스레드를 직접 사용해 비동기 처리를 하려면, 백그라운드 스레드에서 동작을 수행하고 결과에 따라 메인 스레드로 콜백을 보내는 과정을 일일이 관리해주어야 합니다.
또한 스레드를 너무 많이 생성하면 오버헤드가 커지고, 컨텍스트 스위칭(context switching) 비용도 증가합니다. 

### 1.3 비동기 흐름 제어의 단순화

위 두 가지 이슈를 해결하기 위해, 코루틴은 [**쓰레드보다 가볍지만 쓰레드처럼 동작**](6-1-2-코루틴이-스레드보다-가벼운-이유.md)하는 구조를 제공함으로써, 비동기 코드를 동기 코드처럼 작성하게끔 도와줍니다.

## 2. 코루틴의 기본 개념

### 2.1 동기처럼 보이지만 실제로는 비동기

코루틴을 사용하면 `suspend` 함수(일시 중단 함수)를 통해 동기 코드같이 순차적으로 작성하면서도, 중단점(suspension point)에서 자동으로 다른 작업을 처리하도록 전환할 수 있습니다.

[**suspend 함수의 동작 원리 ↗**](6-1-3-suspend-함수의-동작-원리.md)

```kotlin
suspend fun getDataAndSave() {
    val data = fetchDataFromNetwork()  // 네트워크 요청
    saveDataToDatabase(data)           // DB 저장
    showResultToUI(data)               // UI 업데이트
}
```

- `fetchDataFromNetwork()`가 오래 걸리는 동안, 자동으로 다른 코루틴이 실행될 수 있음
- 완료되면 다시 이어서 진행하므로, 별도의 콜백 관리가 줄어듦

### 2.2 구조화된 동시성(Structured Concurrency)

코루틴을 계층 구조로 관리하여 **에러 처리, 취소** 등을 한 곳에서 통합적으로 다룰 수 있게 해주는 개념입니다.  
`CoroutineScope`나 `SupervisorJob` 등을 사용해 부모-자식 관계로 코루틴을 관리합니다.

```kotlin
val scope = CoroutineScope(Dispatchers.Main + SupervisorJob())

scope.launch {
    val data1 = async { fetchDataFromApi1() }
    val data2 = async { fetchDataFromApi2() }

    val result1 = data1.await()
    val result2 = data2.await()
    // 필요한 로직 실행
}
```

- `scope.launch { ... }`로 생성된 코루틴이 부모 스코프
- 내부 `async { ... }`로 생성된 자식 코루틴은 부모 스코프가 취소되면 자동으로 함께 취소

## 3. 코루틴을 구성하는 주요 요소

### 3.1 Job과 Deferred

- **Job**  
  코루틴의 실행 단위를 나타냅니다. `launch { ... }`로 생성한 코루틴은 `Job` 객체를 반환하며, 이를 통해 **취소**나 완료 여부 확인 등이 가능합니다.
  ```kotlin
  val job = scope.launch {
      // 코루틴 내 작업
  }
  job.cancel() // 코루틴 취소
  ```
- **Deferred**  
  코루틴의 실행 결과(반환값)를 표현하는, “Job + 결과값”의 형태입니다. `async { ... }`로 생성한 코루틴은 `Deferred` 객체를 반환하며, `await()` 함수를 통해 결과값을 가져올 수 있습니다.

### 3.2 Dispatcher (스레드 할당 전략)

- `Dispatchers.Main`: 메인(UI) 스레드에서 실행
- `Dispatchers.IO`: 네트워크나 디스크 I/O 같은 블로킹 작업에 최적화
- `Dispatchers.Default`: CPU 연산에 최적화
- `Dispatchers.Unconfined`: 특정 스레드를 강제하지 않음 (테스트나 특수 케이스에서 사용)

### 3.3 CoroutineScope

코루틴이 동작할 범위(스코프)를 지정합니다. 안드로이드에서는 생명주기(Lifecycle)에 맞춰 코루틴을 취소하거나, 에러 처리를 일괄적으로 하기 위해 `lifecycleScope`, `viewModelScope` 등을 자주 활용합니다.

### 3.4 suspend 함수

Kotlin 키워드로, 코루틴 컨텍스트에서만 호출 가능한 일시 중단 함수를 의미합니다.  
**`suspend` 지점에서 자원을 양보**해 다른 코루틴이나 스레드가 수행될 수 있도록 해줍니다.

## 4. 안드로이드와 코루틴

안드로이드에서 코루틴을 활용하면 다음과 같은 장점을 얻을 수 있습니다.

1. **메모리 누수 방지**  
   `Lifecycle`이나 `ViewModel` 범위(scope)에 코루틴을 종속시키면, 화면이 사라질 때 자동으로 취소됩니다.

2. **간결한 비동기 처리**  
   네트워크 요청, DB 처리를 메인 스레드를 차단하지 않으면서도 동기 코드처럼 작성 가능하기에, 가독성이 매우 높아집니다.

3. **구조화된 동시성**  
   에러와 취소, 리소스 정리를 단일 스코프에서 일괄 관리 가능해 복잡도를 낮춰줍니다.

## 5. 대표적인 사용 예시

### 5.1 ViewModel에서 데이터 로드

```kotlin
class MyViewModel : ViewModel() {
    // AndroidX에서 제공하는 viewModelScope 활용
    fun loadData() {
        viewModelScope.launch(Dispatchers.IO) {
            val data = repository.fetchData()
            withContext(Dispatchers.Main) {
                // UI 업데이트
            }
        }
    }
}
```

- UI와 관련 없는 작업은 `Dispatchers.IO`를 통해 백그라운드에서 수행
- UI 업데이트는 `Dispatchers.Main`에서 실행
- `viewModelScope`는 ViewModel의 생명주기와 연결되므로, ViewModel이 클린업될 때 코루틴도 자동 취소

### 5.2 suspend 함수 활용

```kotlin
suspend fun fetchDataAndParse(): ResultType {
    val data = fetchDataFromNetwork()  // 일시 중단 가능
    return parseData(data)             // 일시 중단 가능
}
```

- 네트워크 요청을 포함한 모든 비동기 작업을 `suspend` 키워드를 통해 일시 중단 가능
- 다른 코루틴이 동작하도록 CPU를 양보함

## 마무리

코루틴은 안드로이드에서 비동기 코드를 깔끔하게 작성하고, **구조화된 동시성**을 통해 안정적으로 관리할 수 있는 강력한 도구입니다. 스레드를 직접 다루는 것에 비해 간단하고 안전하며, 메모리 누수나 콜백 지옥 문제를 효과적으로 해결합니다.

- **핵심 개념**: `Job`, `Deferred`, `Dispatcher`, `CoroutineScope`, `suspend`
- **특징**: 구조화된 동시성, 콜백 지옥 해소, 메인 스레드 안전성, 생명주기와 연계된 취소 가능
- **안드로이드 활용**: `lifecycleScope`, `viewModelScope`, `Dispatchers.IO`/`Main`의 적절한 사용

이후에는 코루틴 빌더(`launch`, `async` 등), 취소/예외 처리, 테스트 작성 그리고 Flow(비동기 스트림)로의 확장까지 함께 학습하시면 좋습니다.
