---
title: 6.1 코루틴(Coroutines)
---

코루틴(Coroutines)은 비동기 프로그래밍을 간소화하기 위해 고안된 **경량 스레드** 개념입니다.
Kotlin에서 공식적으로 지원하고 있으며, 안드로이드 개발에서 특히 네트워크 통신, 데이터베이스 I/O 또는 긴 처리가 필요한 작업을 간단하고 효율적으로 구성하기 위해 널리 사용됩니다.
[**동시성(Concurrency)** 과 **비동기(Asynchronous)**](6-1-1-동시성과-비동기.md) 흐름을 직관적으로 표현하고 관리할 수 있게 도와줍니다.



## 1. 코루틴의 등장 배경

### 1.1 콜백(Callback) 방식의 한계

네트워크 통신이나 파일 I/O와 같은 시간이 오래 걸리는 작업을 단순히 콜백으로 처리하면, 코드가 분산되고 중첩 구조(콜백 지옥, *Callback Hell*)로 인해 복잡성이 커집니다.

```kotlin
// 예시: 콜백 지옥이 발생하는 예시
fetchDataFromNetwork { data ->
    saveDataToDatabase(data) { result ->
        showResult(result) { 
            // ...
        }
    }
}
```

### 1.2 스레드(Thread) 직접 제어의 부담

안드로이드에서 스레드를 직접 사용해 비동기 처리를 하려면, 백그라운드 스레드에서 동작을 수행하고 결과에 따라 메인 스레드로 콜백을 보내는 과정을 일일이 관리해주어야 합니다.
또한 스레드를 너무 많이 생성하면 오버헤드가 커지고, 컨텍스트 스위칭(context switching) 비용도 증가합니다. 

### 1.3 비동기 흐름 제어의 단순화

위 두 가지 이슈를 해결하기 위해, 코루틴은 "쓰레드보다 가볍지만 쓰레드처럼 동작"하는 구조를 제공함으로써, 비동기 코드를 동기 코드처럼 작성하게끔 도와줍니다.
