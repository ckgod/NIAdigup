# 7.1 Retrofit

Retrofit은 Square에서 만든 **타입 안전(Type-safe)** 한 HTTP 클라이언트 라이브러리로, 안드로이드와 자바 환경에서 사용됩니다.
네트워크 API 호출을 간단하고 직관적으로 작성할 수 있게 도와줍니다.

## Retrofit 주요 특징

1. **타입 안전(Type-safe)**  
    서버에서 받아온 응답을 미리 정의한 데이터 클래스와 매핑해주어, 컴파일 시점에 타입 검사를 통해 에러를 줄일 수 있습니다.

2. **인터페이스 설계 용이**   
   서버 호출을 담당하는 `interface`와 그 안에 HTTP 메서드(`@GET`, `@POST` 등) 기반의 메서드 시그니처를 작성하는 것만으로 요청/응답 로직을 간결하게 구성할 수 있습니다.

3. **확장성**   
   - ConverterFactory(Gson, Moshi 등)를 교체하여 원하는 JSON 파서나 직렬화 라이브러리를 쉽게 사용 가능합니다.
   - CallAdapter(RxJava, Coroutine 등)를 통해 다양한 비동기 모델을 간단히 지원합니다. 

4. **코루틴 지원**   
   Retrofit 2.6.0 이상부터는 별도의 adapter 추가 없이 코루틴의 `suspend` 함수를 통한 비동기 호출을 지원합니다. 이를 통해 콜백 지옥 문제를 줄이고 직관적인 코루틴 코드를 작성할 수 있습니다.

5. **OkHttp 기반**   
   내부적으로 OkHttp를 사용하여 네트워크 연결, 로깅, 인터셉터, 커스텀 헤더 등을 자유롭게 설정할 수 있습니다.
